# Contributing to NexuBioAuth

First off, thank you for considering contributing to NexuBioAuth!

## 1. Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](../../issues) first. If it's not there, feel free to open a new issue.

## 2. Fork & create a branch

If this is something you think you can fix, then fork NexuBioAuth and create a branch with a descriptive name.

## 3. Implement your fix or feature

At this point, you're ready to make your changes.

## 4. Get the style right

Your patch should follow the PEP8 style guidelines for Python. We also use TailwindCSS for the frontend, so adhere to utility-first styling.

## 5. Make a Pull Request

At this point, you should switch back to your master branch and make sure it's up to date with NexuBioAuth's master branch:

```sh
git remote add upstream https://github.com/lakshanmuruganandam/Nexu-BioAuth-Core.git
git fetch upstream
git rebase upstream/master
```

Then push your branch to your fork and open a Pull Request against our `master` branch.
