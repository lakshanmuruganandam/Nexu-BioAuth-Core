## 🚦 Quickstart Setup (5 Minutes)

### 1. Extract & Install Dependencies
Ensure you have Python 3.9+ installed on your machine.
```bash
pip install -r requirements.txt
```

### 2. Seed Stored Identities (Optional)
Drop photos (`.jpg` or `.png`) of people you want recognized into the `dataset/` folder.
- Example: `dataset/Elon Musk.jpg`
- Example: `dataset/Jane Doe.png`

### 3. Launch the AI Server
```bash
python main.py
```

### 4. Open the Interface
Navigate to `http://localhost:8005` in Chrome, Safari, or Edge. You are ready to analyze!

## ⚙️ Customization Guide

### Adjusting Match Sensitivity
Open `main.py` and modify `SIMILARITY_THRESHOLD`:
```python
# Default is 0.55
SIMILARITY_THRESHOLD = 0.55  
```
- Set to `0.45` for strict high-security applications (fewer false positives).
- Set to `0.65` for lenient hospitality recognition.
